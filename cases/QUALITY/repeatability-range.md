## 1. 창작 업무 요청
창작 요청: 종이 복원 검사실에서 평균 두께는 맞지만 같은 시료를 반복 측정할 때 결과가 흔들려 검사 신뢰도를 점검하려 한다.
독립적으로 설계한 합성 연습이다. 공개 자료는 일반 구현 원리의 참고이며 아래 정책·수치는 창작이다.

## 2. 숨은 원인과 다른 목표
- 장비 반복성이 부족하다.
- 시료를 재배치하는 방법이 다르다.
- 서로 다른 시료 측정을 반복으로 잘못 묶었다.

## 3. 방향을 바꾸는 질문
| 질문 | 답에 따른 변경 |
|---|---|
| 같은 시료와 같은 측정 조건인가? | 아니면 조건별로 분리한 후 비교한다. |
| 범위 기준은 사전에 합의했는가? | 없으면 통과 판정 없이 관측 산포만 제시한다. |
| 정확도까지 판정해야 하는가? | 참값이 없으면 반복성만 보고하고 정확도를 주장하지 않는다. |

## 4. 데이터와 없을 때의 대안
필수 필드는 specimen_id, values(수치 배열, mm), max_range(비음수, mm)다. 한 객체는 동일 시료의 반복 측정이며 최소 2개 관측이 필요하다. null은 미측정이므로 unknown이다. 기준 시료의 참값은 정확도 평가에 추가로 필요하다.
필수 필드가 없으면 결과를 0으로 채우지 않고 unknown을 표시하고 위 질문의 해당 담당자에게 확인한다. 선택 자료는 기준 방법 통과 후 요청한다.

```json
{
  "specimen": "s1",
  "values": [
    "10.0",
    "10.1",
    "10.3"
  ],
  "max_range": "0.2"
}
```

## 5. 기준 방법과 개선 조건
Decimal 문자열로 최대값과 최소값의 차이를 계산하고 허용 범위와 대조한다. 시료별로 출력하여 시료 간 차이를 산포로 합치지 않는다.

여러 작업자와 여러 시료의 반복 구조가 있으면 측정시스템 분산 분해를 별도로 설계한다.

## 6. 최소 구현과 다음 행동
입력 JSON/표 → 필수 필드·단위 검사 → 같은 시료 반복값의 범위가 허용 반복성 안인지 확인한다 → 입력·근거·판정 상태를 한 화면에 표시 → 담당자가 결과를 수용하거나 미확인 자료를 보완한다.
외부 모델·자동 전송 없이 로컬 표 또는 Python 표준 라이브러리로 시작한다. 실행 허용이 미확인이면 계산 절차와 Markdown만 읽는다.

## 7. 합성 입력과 기대 결과
각 input은 위 fixture의 최상위 키를 교체한다. 입력 배열은 전체 교체이며, 기대값은 손계산으로 정한 고정 oracle이다.
| 종류 | 입력 변화 | 기대 결과 | 근거 |
|---|---|---|---|
| 정상 | `{}` | `{"range": "0.3", "status": "outside"}` | 10.3−10.0=.3>.2. |
| 경계 | `{"values": ["10.0", "10.1", "10.2"]}` | `{"range": "0.2", "status": "within"}` | 범위.2경계포함. |
| 정보 부족 | `{"values": ["10.0", null]}` | `"unknown"` | 반복측정한개누락. |

[실행 검사](../../examples/synthetic/check_expansion_b.py)와 [고정 fixture](../../examples/synthetic/expansion_b.json)는 앱 구현을 가져오지 않는 작은 계산 예제다. 통과는 위 입력과 판정에만 해당하며 생산 시스템 검증이 아니다.

## 8. 오용과 범위 축소
낮은 산포가 참값에 대한 정확성을 보장하지 않는다. 전체 GR&R을 실행했다고 표현하지 않는다. 반복 식별키가 없으면 검사 설계부터 확인한다.
추가 패키지 설치가 불가하면 같은 입력을 표와 손계산으로 검사한다. 시간 부족 시 선택 기능을 줄이고 미확인 상태·필수 규칙·기대값 검사는 유지한다.

## 9. 구현물에 대한 담당자 피드백
- 산포가 큰 시료를 다시 측정할 수 있는가?
- 반복성 통과를 정확도 통과로 오해하지 않는가?

담당자에게 결과를 보여주고 실제 다음 행동을 선택하게 한다. 완료 건수/관찰 건수, 오류와 우회 행동을 기록한다. 만족도와 업무 효과는 이 합성 검사로 입증되지 않는다.

## 10. 개발자 본인의 설명 사전 연습
PREP에서만 사용한다. 실제 AI 금지 후속 평가에서는 질문 생성·답변 작성·실시간 코칭을 모두 중단한다.
- 소수 경계를 정확하게 계산한 이유는 무엇인가?
- 참값이 없어서 결론을 내릴 수 없는 부분은 무엇인가?
