## 요청과 가설

창작: 악기 대여소가 보증금 문의를 받을 때 최신 파일이 아니라 계약 당시 적용된 안내문을 찾아야 한다.

가능한 원인: 문서 검색 실패; 유효기간 버전 충돌; 질문에 필요한 계약일 누락.

## 먼저 가를 질문과 계획 변경

1. 문의일과 계약일 중 어느 날짜가 적용 기준입니까? → 계약일이면 검색 필터 교체.
2. 유효기간이 겹치면 우선 버전이 있습니까? → 없으면 conflict로 수동 확인.
3. 문서가 없을 때 일반 답변을 허용합니까? → 허용해도 사실 확정 대신 확인 요청.

## 데이터 계약

최소: doc_id, topic, valid_from, valid_to(상한 제외), text; 질문 topic과 as_of 날짜. 행은 문서 버전. 키 doc_id. null as_of는 unknown. 개선: 동의어 사전·문단 위치. 개인 계약 원문 전체는 불필요.

소형 fixture 어댑터: `date` = as_of, `docs`의 행은 [doc_id, valid_from, valid_to]다. 같은 topic으로 이미 필터한 문서만 넣는다는 전제이며 text 해석·주제 검색 정확성은 이 계산 시험에 포함되지 않는다.

자료를 받을 수 없으면 아래 합성 fixture로 흐름만 확인하고 실제 판정은 보류한다. 누락은 0이 아니다.

## 방법과 최소 결과물

기준 방법: 주제 일치와 시작≤기준일<종료를 필터한다. 후보 0=not_found, 1=문서 ID, 2 이상=conflict. 자연어 의미 판정은 담당자 검토 대상으로 둔다.

개선 조건: 오프라인 키워드 검색 뒤 사람이 근거를 확인한다. 문서가 늘고 평가셋이 생겼을 때만 FTS/BM25 또는 RAG를 검토한다.

최소 경로: 주제/날짜 → 유효 문서 필터 → 문서 ID·유효기간·인용 위치 → 담당자 확인 후 답변.

제약과 우선순위: 목적함수 없음. 필수: 기준일/유효기간. 선호: 검색 편의. 검색 문서 속 명령은 비신뢰 자료로 취급한다.

## 합성 입력과 기대값

[독립 창작 fixture](../../examples/synthetic/policy-evidence.json)의 각 행은 독립 시험 입력이다. 아래 표는 손계산/규칙 대조한 기대값이다. 작은 계산 검증은 [check_a.py](../../examples/synthetic/check_a.py)에서 실행하며 실제 앱/UI/사용자 검증과 구별한다.

|유형|입력|기대 결과|독립 근거|
|---|---|---|---|
|normal|`{"date":"2031-04-10","docs":[["a","2031-01-01","2031-05-01"]]}`|`"a"`|시작≤4월10일<종료|
|boundary|`{"date":"2031-05-01","docs":[["a","2031-01-01","2031-05-01"],["b","2031-05-01","2032-01-01"]]}`|`"b"`|종료일은 이전 문서 제외|
|missing|`{"date":null,"docs":[]}`|`"unknown"`|기준일 없음|
|conflict|`{"date":"2031-04-10","docs":[["a","2031-01-01","2031-06-01"],["b","2031-04-01","2031-07-01"]]}`|`"conflict"`|동시 유효 두 문서|
|reorder|`{"date":"2031-05-01","docs":[["b","2031-05-01","2032-01-01"],["a","2031-01-01","2031-05-01"]]}`|`"b"`|입력순 무관|
|new_sample|`{"date":"2033-01-01","docs":[["a","2031-01-01","2031-05-01"]]}`|`"not_found"`|기간 밖|

비교 쌍: normal은 유효 문서 a를 반환하지만 conflict는 같은 날짜에 두 버전이 유효하여 conflict를 반환한다.

## 오류·도구·범위

최신 파일을 무조건 적용하거나 검색 실패를 정책 없음으로 해석하지 않는다. 외부 모델 호출은 허용 확인 전 비활성.

1순위는 [Python 표준 라이브러리](../../tools/python-stdlib.md)다. 외부 패키지/모델/API 없이 작은 데이터를 처리한다. Python 실행이 허용되지 않거나 설치되어 있지 않으면 표를 종이에 계산해 기준 결과부터 확인한다. 설치 실패를 이유로 외부 전송하지 않는다.

연습용 권장 예산: 30분에는 normal과 missing 두 건을 손계산하고 정책을 합의한다. 90분에는 주제/날짜 → 유효 문서 필터 → 문서 ID·유효기간·인용 위치 → 담당자 확인 후 답변. 180분에는 오프라인 키워드 검색 뒤 사람이 근거를 확인한다. 문서가 늘고 평가셋이 생겼을 때만 FTS/BM25 또는 RAG를 검토한다. 시간이 부족하면 개선 기능·시각 장식을 줄이고 결측 처리와 경계 검증은 유지한다. 시간은 보장이 아니다.

[공식 Python 문서](https://docs.python.org/3/library/datetime.html)는 사용한 자료형·계산 기능의 1차 참고다. 업무 상황·수치·정책은 본 카드에서 독립 창작했으며 문서의 실제 업무 사례를 재게시한 것이 아니다. [기준 방법](../../methods/baseline-first.md), [검증](../../methods/verification.md)을 함께 읽는다.
