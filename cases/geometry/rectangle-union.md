## 요청과 가설

창작: 전시장 바닥 점검 두 팀이 직사각형 구역을 기록했다. 관리자는 실제 점검 면적과 전체 대비 비율을 계산하려 한다.

가능한 원인: 겹친 부분 이중 집계; 도면 단위 불일치; 도형 좌표 뒤집힘.

## 먼저 가를 질문과 계획 변경

1. 구역은 점검 완료 영역입니까 계획입니까? → 계획이면 완료율이라 표시 금지.
2. 좌표가 미터입니까 픽셀입니까? → 축척 없으면 면적 보류.
3. 장애물 뒤 가림을 계산합니까? → 그렇다면 단순 합집합 대신 시야 모델 필요.

## 데이터 계약

최소: rectangle [xmin,ymin,xmax,ymax], unit=m. 작은 예제는 정수 좌표 평면 직사각형. 행은 점검 영역, 선택 ID는 키. null 좌표는 unknown. 개선: 실제 다각형 경계·현장 검증. 위경도를 미터로 취급하지 않는다.

소형 fixture 어댑터: `rects`의 행은 계약의 rectangle 좌표 배열이며 모든 좌표는 정수 미터다. unit=m은 fixture 공통 고정값이다. 실수 좌표·축척 변환 정확성은 별도 검증 대상이다.

자료를 받을 수 없으면 아래 합성 fixture로 흐름만 확인하고 실제 판정은 보류한다. 누락은 0이 아니다.

## 방법과 최소 결과물

기준 방법: 두 사각형은 면적A+면적B−교집합으로 손계산한다. 여러 정수 격자 사각형 예제는 단위 셀 집합으로 독립 대조한다.

개선 조건: 실수/임의 다각형은 기하 라이브러리의 union을 검토하고 유효성·좌표계를 검사한다. 격자 예제를 연속 다각형 근사로 오인하지 않는다.

최소 경로: 좌표/단위 → 유효성 검사 → 합집합 면적 및 중복 면적 → 담당자가 미점검 구역 확인.

제약과 우선순위: 목적함수 없음. 필수: 공통 평면 단위·정상 좌표. 선호: 시각적 중첩. 점·선의 면적은 0.

## 합성 입력과 기대값

[독립 창작 fixture](../../examples/synthetic/rectangle-union.json)의 각 행은 독립 시험 입력이다. 아래 표는 손계산/규칙 대조한 기대값이다. 작은 계산 검증은 [check_a.py](../../examples/synthetic/check_a.py)에서 실행하며 실제 앱/UI/사용자 검증과 구별한다.

|유형|입력|기대 결과|독립 근거|
|---|---|---|---|
|normal|`{"rects":[[0,0,3,2],[2,0,4,2]]}`|`8`|6+4−2=8m²|
|boundary|`{"rects":[[0,0,2,2],[2,0,4,2]]}`|`8`|경계 접촉 면적0:4+4|
|missing|`{"rects":[[0,null,2,2]]}`|`"unknown"`|좌표 누락|
|conflict|`{"rects":[[3,0,1,2]]}`|`"invalid"`|xmin>xmax|
|duplicate|`{"rects":[[0,0,3,2],[0,0,3,2]]}`|`6`|중복 영역 추가 면적0|
|new_sample|`{"rects":[[0,0,4,4],[1,1,2,2]]}`|`16`|완전 포함이면16|

비교 쌍: normal의 두 영역 [0,0,3,2]와 [2,0,4,2]는 8m²다. duplicate의 두 번째 영역이 첫 번째와 완전히 같으면 6m²다. normal과 boundary는 도형 접촉 방식이 달라도 둘 다 8m²여야 한다.

## 오류·도구·범위

면적 단순 합산, 장애물 면적만 빼고 시야 가림 해결 주장, 위경도 거리 계산을 피한다.

1순위는 [Python 표준 라이브러리](../../tools/python-stdlib.md)다. 외부 패키지/모델/API 없이 작은 데이터를 처리한다. Python 실행이 허용되지 않거나 설치되어 있지 않으면 표를 종이에 계산해 기준 결과부터 확인한다. 설치 실패를 이유로 외부 전송하지 않는다.

연습용 권장 예산: 30분에는 normal과 missing 두 건을 손계산하고 정책을 합의한다. 90분에는 좌표/단위 → 유효성 검사 → 합집합 면적 및 중복 면적 → 담당자가 미점검 구역 확인. 180분에는 실수/임의 다각형은 기하 라이브러리의 union을 검토하고 유효성·좌표계를 검사한다. 격자 예제를 연속 다각형 근사로 오인하지 않는다. 시간이 부족하면 개선 기능·시각 장식을 줄이고 결측 처리와 경계 검증은 유지한다. 시간은 보장이 아니다.
