## 요청과 다른 해석

“이동 수리 작업장의 세 수거함을 방문하고 출발점으로 돌아오는 순서를 정하고 싶다.”

- 방문 순서에 따라 이동시간이 달라진다.
- 시간창이나 적재량이 실제 제약일 수 있다.
- 이미 순서가 고정이면 출발시간 계산 문제다.

## 우선 질문과 방향 변화

1. 순서를 바꿀 수 있는가? → 고정이면 순회 최적화를 제외한다.
2. 이동시간은 방향별로 다른가? → 실제 방향 행렬을 받고 대칭을 추정하지 않는다.
3. 적재량·방문 가능 시간은 있는가? → 있으면 단순 최단 순회 검증 이후 제약 경로로 확장한다.

파일에서 이미 확인되는 답은 다시 묻지 않는다. 정책을 결정할 권한자와 기준 시점을 함께 기록한다.

## 데이터 계약과 합성 입력

노드 O 출발점, A/B/C 수거함. times[from][to] 정수 분. 대각선0, 모든 사용 간선 필수. 아래는 의도적으로 대칭인 합성 행렬이며 현실 가정이 아니다.

최소 필수는 아래 판정 필드와 키다. 대표 샘플·스키마로 시작하며 개인 식별 정보는 필요하지 않다. 개선용 데이터는 실제 작업 시간과 오류 기록이다. 전체 이력이나 외부 API는 첫 검증에 없어도 된다. null은 미확인이며 0·false와 다르다. 필수 필드가 없으면 해당 판정을 보류하고 담당자 확인 목록에 남긴다.

## 기준 방법, 제약과 최소 경로

세 지점의 6개 순열을 모두 계산한다. 총 이동시간 최소 경로와 동점 목록을 출력한다. 규모가 커지면 정확 열거 대신 적합한 경로 솔버를 검토하되 시간 제한 상태를 보존한다.

필수: 각 수거함 정확히 한 번, O 출발·복귀. 선호 목적: 총 분 최소. 대기·서비스 시간은 이 fixture에 포함하지 않는다.

행렬 → 후보 6개 총시간 → O-A-B-C-O 및 역순 16분 → 담당자가 출발·수거를 계획한다.

## 기대 결과와 반례

| 유형 | 입력 또는 변경 | 기대 결과 |
|---|---|---|
| 정상 | 기본 행렬 | 최소16분, O-A-B-C-O 또는 역순 |
| 경계 | 방문 지점 없음 | O에 머무름,0분 |
| 정보 부족 | O→A=null | 전체 최적성 판정 보류 |
| 불가능 | A에 연결된 모든 간선 차단 | 완전 방문 불가능 |
| 순서변경 | 행렬 키 순서 변경 | 최소16 유지 |
| 새 샘플 | O↔C를7에서1로 변경 | 최소10분 |

손계산 근거: ABC:3+2+4+7=16, ACB:3+6+4+5=18, BAC:5+2+6+7=20; 나머지는 대칭 역순. OC=1이면 ABC=10.

비슷하지만 다른 두 건: 간선 null은 시간 미확인이다. 차단(infinity)과 달라 불가능 증명이 되지 않는다.

작은 계산 예제는 [check_c.py](../../examples/synthetic/check_c.py)에서 별도 표준 라이브러리 계산으로 확인한다. 각 수용 테스트 행의 기대값은 소형 오라클 계산으로 확인한다. 전체 앱·화면·DB 동시성은 구현하거나 검증하지 않았으며, 기대값 검증과 구현물 테스트 통과는 다르다. 실행 범위는 해당 스크립트 출력과 검증 보고서를 따른다.

## 답변이 바뀌면 수정할 계획

- 시간창이 생기면 이동 후 도착·대기·서비스를 순서별 시뮬레이션한다.
- 복귀 불필요면 마지막 O 간선을 빼고 열린 경로를 다시 평가한다.

## 피할 구현과 축소 기준

- 고정 경로 시간표에는 방문 순서 최적화가 맞지 않는다.
- 직선거리로 실제 이동시간을 검증했다고 하지 않는다.
- 시간 부족이면 세 지점 완전 열거와 데이터 누락 경고까지만 만든다.

1순위 도구는 [Python 표준 라이브러리](../../tools/python-stdlib.md)다. 이 작은 합성 입력에는 패키지 설치·외부 호출이 필요 없다. Python도 실행할 수 없으면 표에 후보를 전부 적고 손계산한다. 대규모 개선 도구는 설치·규정·입력 적합성이 확인된 이후 별도 선택한다.

## 연습 시간 예산과 효과 측정

30분: 여섯 합계 대조. 90분: 입력 행렬과 경로 비교. 180분: 시간창을 추가하되 새 검증 작성. 권장 연습 예산이다.

총 모델 이동시간과 미방문 수를 측정한다. 실제 운행시간은 현장 기록이 있어야 비교된다. 이 합성 예제만으로 실제 조직의 시간 절감·만족도·수익 향상을 주장할 수 없다.
