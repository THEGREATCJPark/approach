# Python 표준 라이브러리

- id: `python-stdlib`
- 적합: CSV/JSON 정리, Decimal 금액, 작은 완전탐색, 상태 판정
- 부적합: 대규모 조합 탐색, 불명확한 자연어 판정의 자동 확정
- 확인: 2026-11-05 / `smoke_tested` / Python 3; 실행 확인 3.12.14
- [공식 저장소·홈](https://github.com/python/cpython) · [공식 문서와 예제](https://docs.python.org/3/library/decimal.html) · [라이선스 원문](https://docs.python.org/3/license.html)

## 먼저 확인할 것

Decimal 입력은 float를 거치지 않는다. 시간대는 명시하고 결측은 0으로 바꾸지 않는다.

## 입출력·설치

- 입력: 행·키·단위·누락 의미가 확정된 JSON/CSV
- 최소 출력: 판정·근거·미확인 상태를 가진 JSON 한 건
- 설치 조건: 추가 패키지 없음. 제공 Python 고정 버전을 그대로 사용
- 설치 불가 대안: 문자열 Decimal 계산 또는 표 수동 계산

## 실행 조건

unknown; 현재 과제 규정 확인 전 설치/외부 통신/자동 조작 비활성. 버전 변경을 기본 동작으로 삼지 않는다.
외부 호출: 기본 로컬 연산은 외부 호출·자격증명 불필요. 설치/문서 조회만 네트워크를 사용할 수 있고, 별도 I/O 코드 추가 시 다시 확인.
자격증명: 로컬 기본 예제는 불필요.
비용: 일반 집계는 행 수에 비례하는 기준부터 시작. permutation은 n!로 증가하므로 작은 fixture 전용; 입력 수 제한을 둔다.

## 확인 범위

라이선스: PSF-2.0; 포함 구성요소별 조건 별도. 종속 패키지·복사하는 코드의 개별 조건은 별도 확인한다.
문서와 예제 경로를 실제 열어 해당 API·설명 존재를 확인했다. mutable URL을 확인한 기록이며 릴리스 전체나 설치 성공을 인증하지 않는다.

로컬 smoke: Python 3.12.14에서 `Decimal("0.1") + Decimal("0.2")` 기대·실제 `0.3`. 전체 표준 라이브러리 검증은 아니다.
