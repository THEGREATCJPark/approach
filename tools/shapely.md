## 먼저 확인할 것

합집합으로 중복 면적 제거. 도형 유효성·경계 접촉 정책을 확인한다. 시야 가림은 별도 ray/visibility 모델이 필요하다.

## 입출력·설치

- 입력: 같은 투영좌표계의 유효 geometry와 단위
- 최소 출력: 합집합 면적·충돌 쌍·잘못된 geometry 목록
- 설치 조건: 허용된 고정 버전 wheel; GEOS 포함 여부 확인
- 설치 불가 대안: 축 정렬 사각형 손계산 또는 격자 근사와 오차 명시

## 실행 조건

unknown; 현재 과제 규정 확인 전 설치/외부 통신/자동 조작 비활성. 버전 변경을 기본 동작으로 삼지 않는다.
외부 호출: 기본 로컬 연산은 외부 호출·자격증명 불필요. 설치/문서 조회만 네트워크를 사용할 수 있고, 별도 I/O 코드 추가 시 다시 확인.
자격증명: 로컬 기본 예제는 불필요.
비용: polygon 수·정점 수·겹침 수가 커지면 연산·메모리 비용 증가. 유효성 검사와 공간 인덱스 후보 축소를 먼저 측정한다.

## 확인 범위

라이선스: BSD-3-Clause; GEOS 등 별도. 종속 패키지·복사하는 코드의 개별 조건은 별도 확인한다.
문서와 예제 경로를 실제 열어 해당 API·설명 존재를 확인했다. mutable URL을 확인한 기록이며 릴리스 전체나 설치 성공을 인증하지 않는다.

패키지 설치와 공식 예제 실행은 이번 기록에서 **미실행**. 기능 설명 확인을 실행 성공으로 취급하지 않는다.

## 관련 문제 구조

`GEOMETRY` 영역에서 조건을 확인한 후 선택한다. [라우터](../ROUTER.md)로 돌아가 데이터와 반증 질문을 먼저 비교한다.
