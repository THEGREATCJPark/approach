# Playwright — 선택적 사전 QA

- id: `playwright`
- 적합: 사전 연습 또는 자동 브라우저 조작이 명시 허용된 UI 검증
- 부적합: Computer Use 금지/unknown 환경, 감독 화면·메신저 자동 조작
- 확인: 2026-11-05 / `docs_verified` / Node.js와 호환 Playwright/browser 버전; 실행 미검증
- [공식 저장소·홈](https://github.com/microsoft/playwright) · [공식 문서와 예제](https://playwright.dev/docs/intro) · [라이선스 원문](https://raw.githubusercontent.com/microsoft/playwright/main/LICENSE)

## 먼저 확인할 것

기본 실행 경로에서 제외. 브라우저 다운로드·웹앱 호출은 외부 통신일 수 있다. 녹화·trace에 민감 입력이 남을 수 있어 공개하지 않는다.

## 입출력·설치

- 입력: 허용된 로컬 앱 URL·사용자 흐름·기대 화면
- 최소 출력: 실패 지점·trace·스크린샷; 업무 효과는 별도
- 설치 조건: 기존 고정 버전 먼저 확인. 허용 시 @playwright/test와 대응 browser binary 준비
- 설치 불가 대안: 수동 UI 확인 + 계산·단위 테스트

## 실행 조건

unknown; 현재 과제 규정 확인 전 설치/외부 통신/자동 조작 비활성. 버전 변경을 기본 동작으로 삼지 않는다.
외부 호출: 설치 시 패키지·브라우저 다운로드. 실행 시 대상 앱과 하위 리소스에 네트워크 요청 가능. 로컬 테스트라도 별도 외부 전송 여부 확인.
자격증명: 로컬 기본 예제는 불필요.
비용: 브라우저 바이너리 다운로드·프로세스 메모리·trace 용량이 큼. 단일 브라우저 핵심 흐름부터; 허용되지 않으면 실행 비용 0인 수동 경로로 전환.

## 확인 범위

라이선스: Apache-2.0; 브라우저 배포물 조건 별도. 종속 패키지·복사하는 코드의 개별 조건은 별도 확인한다.
문서와 예제 경로를 실제 열어 해당 API·설명 존재를 확인했다. mutable URL을 확인한 기록이며 릴리스 전체나 설치 성공을 인증하지 않는다.

패키지 설치와 공식 예제 실행은 이번 기록에서 **미실행**. 기능 설명 확인을 실행 성공으로 취급하지 않는다.

## 관련 문제 구조

`INTERACTIVE`, `EVENT` 영역에서 조건을 확인한 후 선택한다. [라우터](../ROUTER.md)로 돌아가 데이터와 반증 질문을 먼저 비교한다.
