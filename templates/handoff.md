# 결과 인계

이 빈 양식은 허용된 별도 작업 공간에 복사해 사용한다. 실제 입력·담당자 답변·판단 기록·코드·평가 문항을 공개 참고 저장소에 쓰지 않는다. 필요한 의사결정 근거만 기록하되 의무 보존 기록을 숨기거나 삭제하지 않는다.

- 결과물 위치와 허용된 제출 경로:
- 실행 환경·버전·의존성:
- 설치 불가 시 대안:
- 실행 명령과 입력 준비:
- 대표 결과 재현법:
- 데이터 출처·버전·가정:
- 핵심 결정과 변경 근거:
- 실제 실행한 검사·결과:
- 미실행 검사와 이유:
- 확인된 오류·미완성·영향:
- 운영 담당·정책 변경·되돌림 절차:
- 다음 작업의 시작점:

실제 과제 작업물을 공개 참고 저장소로 푸시하지 않는다. 제출·배포·외부 전송 허용은 별도로 확인한다.
