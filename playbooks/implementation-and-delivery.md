# 재현 가능한 결과를 전달한다

[시작](../START_HERE.md) · [규정 확인](../RULES_GATE.md)

적용: PREP 또는 허용된 TASK. NO_AI_REVIEW에서는 질문 생성·답변 작성·실시간 코칭을 중단한다. 실제 기록은 별도 허용 작업 공간에 남긴다.

## 입력

최소 경로, 인수 기준, 허용된 제출 형식·경로.

## 행동

작은 변경 단위마다 관련 검사를 실행한다. 담당자 피드백을 오류 수정/필수 누락/선택 개선으로 나눈다. 실행법·입력 스키마·환경 버전·미완성을 적고 깨끗한 시작 조건에서 재현한다. 실제 과제 결과는 공개 참고 저장소에 쓰거나 푸시하지 않는다. 배포·외부 전송은 별도 허용이 필요하다.

## 남길 기록

[인계서](../templates/handoff.md), [근거 로그](../templates/evidence-log.md), [피드백](../templates/feedback-log.md).

## 다음 단계 기준

수신자가 입력과 실행 절차로 결과를 재현하고, 확인되지 않은 범위를 식별한다.

## 중단·축소 조건

제출 규정이 불명확하면 외부 배포 대신 허용 공간의 로컬 결과까지 준비한다. 실행하지 않은 검사는 not-run으로 적는다.
