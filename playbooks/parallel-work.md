# 허용된 경우에만 역할을 나눈다

[시작](../START_HERE.md) · [규정 확인](../RULES_GATE.md)

적용: PREP 또는 허용된 TASK. NO_AI_REVIEW에서는 질문 생성·답변 작성·실시간 코칭을 중단한다. 실제 기록은 별도 허용 작업 공간에 남긴다.

## 입력

병렬 AI 세션 허용 근거, 공통 요구, 파일 소유권, 자원 예산.

## 행동

기본은 주 구현 하나와 독립 검증이다. 병렬 허용이 확인될 때만 좁은 조사·작은 실험·검증 역할을 나눈다. 각 역할의 입력·출력·완료 기준·수정 가능 파일을 지정한다. 요구 변경은 모두에게 통보하고 통합 담당자가 충돌과 결과를 확인한다.

## 남길 기록

역할별 파일 소유권, 공통 데이터 계약, 검증 결과, 통합 결정. [근거 로그](../templates/evidence-log.md)에 실제 실행 여부를 남긴다.

## 다음 단계 기준

별개 결과가 공통 인수 기준으로 통합되고 추가 확인 없이 재현된다.

## 중단·축소 조건

여러 터미널이 열려도 복수 AI 세션 허용을 뜻하지 않는다. unknown이면 직렬로 진행한다. worktree는 전역 설정·패키지 캐시·외부 서비스·메모리·토큰을 격리하지 않는다.
