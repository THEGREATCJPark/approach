# 단순한 기준 방법부터 선택한다

[시작](../START_HERE.md) · [규정 확인](../RULES_GATE.md)

적용: PREP 또는 허용된 TASK. NO_AI_REVIEW에서는 질문 생성·답변 작성·실시간 코칭을 중단한다. 실제 기록은 별도 허용 작업 공간에 남긴다.

## 입력

문제 구조, 데이터 크기, 필수조건, 시간·권한·설치 제약.

## 행동

규칙표·집계·정렬·전수열거·키워드 검색으로 기준 결과를 만든다. 부족한 점을 측정한 뒤 최적화·통계·모델 도입을 검토한다. 도구 카드의 non_fit과 fallback을 읽는다. 추천은 금지·가용 조건 필터를 순위보다 먼저 적용한다.

## 남길 기록

[결정 로그](../templates/decision-log.md): 기준 방법, 개선 후보, 채택 이유, 반대 근거, 전환 조건.

## 다음 단계 기준

왜 이 방법이 현재 데이터와 제약에 맞는지, 더 복잡한 방법이 필요한 조건을 설명한다.

## 중단·축소 조건

설치 실패 시 수작업 기준 계산 또는 표준 라이브러리로 줄인다. 필수조건 위반을 선호 점수로 상쇄하지 않는다. 솔버 시간초과 unknown을 infeasible로 바꾸지 않는다.
