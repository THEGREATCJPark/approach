# 무엇을 결정하는 작업인가

[시작](../START_HERE.md) · [규정 확인](../RULES_GATE.md)

적용: PREP 또는 허용된 TASK. NO_AI_REVIEW에서는 질문 생성·답변 작성·실시간 코칭을 중단한다. 실제 기록은 별도 허용 작업 공간에 남긴다.

## 입력

과제 원문, 제출 형식, 현재 규정, 사용자 역할. 자료가 없으면 준비 절차만 안내한다.

## 행동

사용자가 결과를 본 뒤 할 동작을 한 문장으로 적는다. 분석만 필요한 요청에 앱 제작을 추가하지 않는다. 규정의 allowed / forbidden / unknown과 실행 환경을 확인하고 보호 대상 행동은 unknown이면 보류한다. 제공 자료에서 답을 찾은 뒤, 설계를 바꿀 질문만 최대 3개 남긴다.

## 남길 기록

[작업 요약](../templates/task-brief.md): 사용자·결정·입력·출력·필수조건·제외 범위.

## 다음 단계 기준

결과 한 건, 이를 사용할 사람, 제출물과 완료 기준을 설명할 수 있다.

## 중단·축소 조건

정책 권한자나 자료 접근 권한이 불명확하면 해당 판정을 보류한다. 화면 배치처럼 되돌릴 수 있는 선택만 가정하고 표시한다.
