# 구현과 다른 경로로 기대값을 확인한다

[시작](../START_HERE.md) · [규정 확인](../RULES_GATE.md)

적용: PREP 또는 허용된 TASK. NO_AI_REVIEW에서는 질문 생성·답변 작성·실시간 코칭을 중단한다. 실제 기록은 별도 허용 작업 공간에 남긴다.

## 입력

정상·경계·누락·충돌·중복·새 샘플의 입력과 기대값.

## 행동

작은 데이터의 손계산 또는 별도 전수열거 결과와 대조한다. 같은 생산 함수를 다시 호출하는 테스트는 독립 계산이 아니다. 규칙 판정은 경계 바로 아래/같음/위, 집계는 분모와 누락, 상태 변경은 재시도와 원자성, 게임은 프레임 시간과 재시작을 검사한다. 변형 검사는 성립 조건을 먼저 적는다.

## 남길 기록

[인수 검사](../templates/acceptance-tests.md): 입력·기대·근거·실제·환경·pass/fail/not-run. 정적 검사/단위 테스트/수동 UI/사용자 검증을 분리한다.

## 다음 단계 기준

필수 규칙의 대표 반례가 통과하고, 미검증 사항과 잔여 위험이 명시되었다.

## 중단·축소 조건

브라우저 자동화가 금지되거나 unknown이면 자동 QA를 실행하지 않는다. 허용된 계산·단위 테스트와 수동 UI 확인으로 바꾼다. 테스트 통과만으로 현장 효과를 주장하지 않는다.
