# 확장 C 독립 내용·계산 검토

검토일: 2026-11-05. 작성자와 다른 검토 세션에서 RANKING·MOBILITY·DEPENDENCY 표준 카드 각 6건, 총 18건의 계약·방법·기대값과 계산 스크립트를 읽었다. 합성 사례만 대상으로 했으며 실제 업무 원자료는 사용하지 않았다.

## 실제 실행과 내용 검토

- Python 3.12.14에서 `python examples/synthetic/check_expansion_c.py`를 실행했다. 최초 제공 fixture 54개는 54개 통과했다.
- 분수 순위, 정규화 거리, 성분 교집합, 경과일 경계, 점수 합계, 분할 불가 용량, 대기·서비스 시각, minimax, 연결요소, 용량 제한 배정, 잔여/초과 수량, 방향·종류 필터, 제거 전후 경로, 3상태 AND/OR, 직렬 계수 곱, 근거 기간, 복수 관계 집계를 표의 손계산과 대조했다.
- 기존 심화 사례와 비교했다. 고정 경로의 출발 가능구간과 주어진 출발시각의 대기 전파는 결정변수가 다르고, 전체 도달경로와 종류별 직접 이웃은 조회 범위가 다르다. 상충 출처를 비교하도록 수정한 관계 근거 카드는 단순 정책 유효기간 검색과 판정 구조가 다르다.
- 각 카드의 정상·경계·정보 부족 시험, 세 분기 질문, 데이터 단위와 키, 사용자 피드백과 PREP 설명 연습 분리를 확인했다. 순위·형식 검사는 실제 추천 만족도나 관계의 인과성을 입증하지 않는다.
