# 확장 현황과 완료 조건

현재 목표는 15영역 × 심화 2건 = 30건의 근거 있는 첫 묶음이다.
총 120건을 위한 **추가 90건은 미작성**이다. 제목뿐인 카드를 catalog에 넣거나 완성 수에 합산하지 않는다.

다음 확장 때 각 영역 6건을 추가하되 기존 카드와 다른 결정·입력 구조·필수조건·검증 기준을 사전에 명시한다.
업종·인명·수치만 바꾸는 것은 새 사례가 아니다. 아래는 작업 방향이며 완성 사례가 아니다.

| 영역 | 추가 사례에서 분리할 구조 |
|---|---|
| ANALYTICS | 통화 환산, 가격/물량 분해, 정정 버전, 예측 시나리오, 주장-근거, 결측 비교 |
| SUPPORT | 유형 분류, 유사 문의 묶기, 답변 검토, 이관 권한, 인계 요약, 원인 분석 |
| COACH | 장황함, 사실 불확실성, 공개 경계, 번역 의미, 수정 전후, 반론 대응 |
| EVENT | 자격, 대기 승격, 취소 재신청, 사건 재생, 승인 이력, 상태별 통지 |
| GEOMETRY | 설치 비용, 예산 커버리지, 중요도 가중, 설치 불가, 축척, 좌표 변환 |
| LEARNING | 진단, 짧은 설명, 분류 체계, 선수 관계, 근거 검색, 적용 평가 |
| OPERATIONS | 위치 벡터, 장비 비교, 작은 지속 변화, 정비 전후, 조건 혼합, 후속 점검 |
| PLANNING | 반복 간격, 고정 일정, 대체 자원, 수요 발주, 공급 중단, 불가능 사유 |
| POLICY | 승인 권한, 증빙 누락, 중복 청구, 반려 재제출, 버전 변경, 다음 행동 |
| QUALITY | lot 계층, 측정 신뢰도, 비용/위험 분리, 누락 시험, 단계 전환, 되돌림 |
| RANKING | 신규 사용자, 속성 유사도, 금지 품목, 최근 반복, 설명, 정답 없는 평가 |
| MOBILITY | 용량, 시간창, 거점 선택, 수요 군집, 최대 이동시간 공평성, 미배정 |
| INTERACTIVE | 자원 소모, 간단한 봇, 영역 축소, 동시 종료, 시간 스텝, 다중 사용자 범위 |
| TRANSACTION | 심사/실행 분리, 사유 코드, 수동 검토, 시점 불일치, 이력, 충돌 복구 |
| DEPENDENCY | 관계 유형, 병목, 공급 중단, 계수 민감도, 출처 충돌, 시각화/전망 경계 |

완료 조건: 독립 창작 설명, 데이터 계약, 분기 질문, 기준 방법, 최소 경로, 정상/경계/정보 부족 기대값,
적용 제외 조건, 업무 피드백 2개, PREP 설명 질문 2개, 실제 검증 결과, 출처·공개 검토를 모두 갖춘다.
심화로 세려면 작은 fixture와 서로 다른 6개 이상 시험, 손계산, 계획 변경 분기, 시간 예산, 한계도 필요하다.
새 표본 검증과 이전 회귀 검증을 구별한다. 카탈로그에 넣기 전에 기존 사례와 겹치는 판정을 검토한다.
