# 시험 전 개발자 설명 연습 전용

**PREP의 창작 연습이나 허용된 준비 자료에만 적용한다. 실제 AI 금지 후속 평가(NO_AI_REVIEW)에서는 질문 생성·답변 작성·실시간 코칭을 모두 중단한다.** 실제 평가 문제를 가져와 연습으로 이름만 바꾸어 지원하지 않는다. 허용 여부가 unknown이면 보호 대상 지원을 보류한다. [규정 확인](../RULES_GATE.md)을 우선한다.

이 절차는 개발자가 자신의 선택을 직접 설명하도록 돕는다. 구현물을 써 보는 사용자의 업무 피드백은 [prototype-feedback](prototype-feedback.md)이다.

## 필요한 증거

허용된 연습 결과물의 코드·작업 요약·결정 로그·테스트 출력·미완성 목록 중 실제로 존재하는 것만 읽는다. 존재하지 않는 성과나 실패를 질문의 전제로 만들지 않는다. 자료가 없으면 자료 준비까지만 안내한다.

## 진행

1. [질문 은행](question-bank.md)에서 증거와 관련된 질문 하나를 선택한다.
2. 먼저 개발자가 직접 답한다. 모범답안을 미리 제공하거나 암기시키지 않는다.
3. 답변을 실제 파일과 대조해 근거 누락·과장·모순을 지적한다. 코드 성공과 현장 효과를 구별한다.
4. 필요한 후속 질문 하나를 하고 본인이 답을 수정하게 한다.
5. 설명할 수 없는 부분은 검증 또는 기록이 필요한 지점으로 남긴다.

빈 구조만 필요할 때: `판단 → 근거 → 검증 → 한계`.

질문 은행은 공식 채점 기준이나 실제 질문 예측이 아니다. 실제 평가로 전환되면 즉시 중단하고 본인이 응답하도록 안내한다. 자동 제출·외부 전송 기능은 제공하지 않는다.
