# 단순 기준 먼저 / Baseline-first

- id: `baseline-first`
- 사용할 때: 복잡한 모델·최적화가 정말 필요한지 판단해야 한다
- 사용하지 않을 때: 필수 안전·품질 조건을 baseline이라며 생략한다
- [공개 1차 참고](https://scikit-learn.org/stable/modules/generated/sklearn.dummy.DummyClassifier.html) — 2026-11-05 확인.

## 5~15분 실행

규칙·집계·greedy 등 가장 단순한 방식의 실패 예와 비용을 기록한다. 같은 입력·지표로 개선법을 비교할 수 있는 조건을 정한다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

기준 결과/실패 입력/비교 지표/개선 채택 조건

## 중단·오용 방지

필수 조건 만족 후 개선 가치가 없으면 기준 방법 유지.

피할 오용: 쉬운 표본만 골라 복잡한 방법의 우월함을 주장한다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.
