- 사용하지 않을 때: 사고 뒤 책임자를 정하는 용도로 쓴다
- [공개 1차 참고](https://www.gary-klein.com/premortem) — 2026-11-05 확인.

## 5~15분 실행

이 결과를 믿고 다음 행동을 했는데 실패했다고 가정한다. 단위 오류·기한 오해·중복 실행 중 가능한 원인 두 개와 조기 감지 검사를 만든다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

실패 원인/노출 시점/방지 검사/담당/남은 위험

## 중단·오용 방지

위험 하나를 검사 또는 범위 제한으로 바꾸면 종료.

피할 오용: 근거 없는 공포 목록을 늘리고 실제 계획을 바꾸지 않는다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.

## 다음 연결

관련 사례의 데이터 계약과 정상·경계·정보 부족 기대값을 읽는다. [진입점](../START_HERE.md)에서 실제 허용 범위를 먼저 확인한다. 설명 연습은 사전 연습에서만 사용하며 AI 금지 실제 평가에는 적용하지 않는다.
