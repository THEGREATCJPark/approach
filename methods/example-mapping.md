# 규칙과 예외 / Example Mapping

- id: `example-mapping`
- 사용할 때: 같은 요청을 담당자와 개발자가 다르게 해석한다
- 사용하지 않을 때: 이미 확인된 규칙을 문서 장식용 카드로 복제한다
- [공개 1차 참고](https://cucumber.io/docs/bdd/example-mapping/) — 2026-11-05 확인.

## 5~15분 실행

규칙 하나 아래 정상·경계·보류 예를 쓰고 답 없는 질문을 분리한다. 서로 다른 결과가 필요한 최소 두 입력을 담당자에게 확인한다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

규칙→입력→기대 출력과 미해결 질문

## 중단·오용 방지

구현을 바꾸는 미해결 질문이 없거나 보류 경로가 합의되면 종료.

피할 오용: 빈칸을 개발자가 임의 정책으로 채운다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.

## 다음 연결

관련 사례의 데이터 계약과 정상·경계·정보 부족 기대값을 읽는다. [진입점](../START_HERE.md)에서 실제 허용 범위를 먼저 확인한다. 설명 연습은 사전 연습에서만 사용하며 AI 금지 실제 평가에는 적용하지 않는다.
