## 5~15분 실행

입력 하나가 처리·저장·출력·사용자 다음 행동까지 흐르게 만든다. 표본과 실제 연결을 구별하고 실패 응답도 하나 연결한다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

재현 명령, 입력 한 건, 실제 출력, 다음 행동

## 중단·오용 방지

한 건이 처음부터 끝까지 재현되면 범위를 확장.

피할 오용: 화면 껍데기만 완성하고 핵심 계산을 임시 숫자로 남긴다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.

## 다음 연결

관련 사례의 데이터 계약과 정상·경계·정보 부족 기대값을 읽는다. [진입점](../START_HERE.md)에서 실제 허용 범위를 먼저 확인한다. 설명 연습은 사전 연습에서만 사용하며 AI 금지 실제 평가에는 적용하지 않는다.
