# 업무 흐름 복원 / Domain Storytelling

- id: `domain-storytelling`
- 사용할 때: 누가 어떤 자료로 판단하고 넘기는지 불명확하다
- 사용하지 않을 때: 이미 흐름이 확인되고 단일 계산만 수정한다
- [공개 1차 참고](https://domainstorytelling.org/) — 2026-11-05 확인.

## 5~15분 실행

최근 한 건을 담당자·행동·자료·순서로 적는다. 다시 읽어 틀린 연결을 수정받는다. 예외는 같은 그림에 섞지 말고 두 번째 흐름으로 분리한다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

주체→입력→판단→전달의 4칸 기록과 아직 모르는 연결 하나

## 중단·오용 방지

한 건의 입력과 다음 행동을 담당자가 확인하면 종료.

피할 오용: 상상한 정상 절차를 실제 관찰로 포장하거나 조직 전체 모델을 먼저 만든다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.

## 다음 연결

관련 사례의 데이터 계약과 정상·경계·정보 부족 기대값을 읽는다. [진입점](../START_HERE.md)에서 실제 허용 범위를 먼저 확인한다. 설명 연습은 사전 연습에서만 사용하며 AI 금지 실제 평가에는 적용하지 않는다.
