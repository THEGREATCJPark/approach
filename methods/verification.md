# 독립 검증 / Verification

- id: `verification`
- 사용할 때: 계산·상태·제약 결과가 실제 행동을 바꾼다
- 사용하지 않을 때: 증거가 없는 효과 주장에 테스트 통과 표시를 붙인다
- [공개 1차 참고](https://hypothesis.readthedocs.io/en/latest/quickstart.html) — 2026-11-05 확인.

## 5~15분 실행

생산 함수와 별도 손계산을 대조한다. 경계·결측·충돌을 넣고 성립 조건을 설명할 수 있는 변형 관계 한 개만 검사한다.

시간은 이 저장소의 연습 권장 예산이며 원저자의 규격이나 실행시간 보장이 아니다. 아래 절차·기록 형식은 업무 도구 개발에 맞춘 독립적인 적용 제안이다.

## 남길 결과

입력/기대/근거/실제/환경/pass-fail-not-run

## 중단·오용 방지

차이를 해소하고 미검증 범위를 명시하면 종료.

피할 오용: 동일 함수 두 번 호출을 독립 검증이라 부르거나 성립하지 않는 불변식을 강제한다. 실제 업무 증거가 없으면 합성 연습으로 표시한다.
